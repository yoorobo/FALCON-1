# FALCON-1 시스템 요구사항 (System Requirements)

버전:** v2.0 (PoC Must 24건 전면 재작성, 가이드라인 v1.2 기반) **최종 갱신:** 2026-05-05 **작성 기준:** `docs/requirements/sr_authoring_guideline.md` v1.2

이 문서는 사용자 요구사항(UR) 중 PoC 환경의 필수(Must) 기능을 시스템이 어떻게 달성할지에 대한 논리적/정량적 정책을 정의합니다. 세부 구현과 기술 종속 사항은 지정된 상세설계 문서로 위임합니다.

**작성 컨벤션 (v1.2)**:

-

-

- 

D4: 단순 일련번호 `SR-NN` (카테고리 분류는 표 섹션 제목)

| **SR-04** | UR_A01 | (예외) 음성 인지 신뢰도가 임계값(임계값 표 P-04) 미만이면 해당 입력은 미인식으로 처리하고 SR-08의 안내 절차를 따른다. | 임계값: **P-04**<br>분기: `behavior_tree.md` |
| **SR-05** | UR_A01 | (예외) 인지 신뢰도가 임계값 이상이지만 명령 집합에 없는 발화로 매칭되면, 해당 입력은 미등록 명령으로 처리하고 SR-08의 안내 절차를 따른다. | 분기: `behavior_tree.md` |
| **SR-06** | UR_A02 | (정상) 유효 명령으로 등록되면 임계 시간(임계값 표 P-06) 이내에 LED를 초록색으로 점멸하고, 스피커로 "알겠습니다" 음성을 1회 출력한 뒤 해당 명령의 실행 시퀀스로 진입한다. | 임계값: **P-06**<br>UI 정책: 본 SR 정의 상태 전환: `state_machine.md` |
| **SR-07** | UR_A02 | (알림) 호출 피드백 음성과 LED 점멸은 비상 정지 상태(SR-65~SR-67)에서는 출력하지 않으며, 비상 정지 알림이 우선한다. | 우선순위 로직: `state_machine.md` |
| **SR-08** | UR_A03 | (예외) 음성 입력이 미인식(SR-04) 또는 미등록 명령(SR-05)으로 분류되면, 어떠한 기계적 구동도 개시하지 않고 LED를 노란색으로 점멸하며 "다시 말해주세요" 음성을 1회 출력한 뒤 직전 대기 상태를 유지한다. | UI 정책: 본 SR 정의 |
| **SR-09** | UR_A03 | (전제조건) 미인식·미등록 명령 처리 중에는 새 음성 입력을 임계 시간(임계값 표 P-09) 동안 무시하여 연속 오인식으로 인한 의도치 않은 동작 트리거를 방지한다. | 임계값: P-09 |
