# FALCON-1: User Requirements Specification

> **버전:** v1.3
> **문서 종류:** User Requirements (UR)
> **원본:** `FALCON1_UR_v1_3.docx`

---

## 표기 규칙

**Reporter**
- ● **User** (작업자)
- ◆ **Admin** (관리자)
- ■ **Safety** (안전관리자)

**Priority**
- **Must** = PoC 필수
- **Should** = PoC 권장
- **Could** = 여건 허락 시

**Phase**
- **PoC** = v1.0 통제 환경 검증
- **Post-PoC** = 양산/현장 배포 단계

> ⚠️ 모든 정량 기준(거리, 속도, 시간, 성공률 등)은 SR(System Requirements) 문서에 명시되어 있습니다.

## C. 공구 입출고

| UR ID | Phase | Priority | Description | Reporter | 검증 방법 | Dependency |
|-------|-------|----------|-------------|----------|-----------|------------|
| **UR_C01** | PoC | **Must** | 로봇은 등록된 공구를 수납장의 지정된 자리에서 로봇 팔로 꺼낸다. | ● User | 공구 꺼내기 성공률 측정 | - |
| **UR_C02** | PoC | **Must** | 공구를 꺼내는 동작은 로봇 본체가 완전히 멈춘 후에만 시작한다. | ◆ Admin | 이동 중 팔 동작 발생 여부 확인 | UR_C01 |
| **UR_C03** | PoC | **Should** | 꺼내기 실패 시 제한된 횟수만 재시도 후, 작업자와 관리자에게 알린다. | ◆ Admin | 실패 시 알림 및 재시도 횟수 확인 | UR_C01 |
| **UR_C04** | PoC | **Must** | 로봇은 돌려받은 공구를 원래 자리에 넣는다. 자리가 차 있으면 넣지 않고 알린다. | ● User | 넣기 성공률 및 오배치 여부 확인 | - |
| **UR_C05** | Post-PoC | **Should** | 등록 안 된 공구나 파손된 공구를 받으면 수납장에 넣지 않고 별도 임시 트레이에 둔다. | ● User | 미등록 공구 거부 여부 확인 | UR_C04 |
| **UR_C06** | PoC | **Must** | 모든 공구는 미리 등록(모양, 잡는 방법, 자리 지정 등)해야 호출/회수가 가능하다. | ◆ Admin | 등록 절차 수행 시험 | - |

| **UR_D06** | PoC | **Must** | 공구를 건네는 중 작업자가 놀라서 피하거나 뒤로 물러서면, 로봇은 즉시 멈추고 안전 자세로 돌아간다. | ● User | 후퇴 시 즉시 정지 여부 확인 | UR_D01 |

## E. 안전

| UR ID | Phase | Priority | Description | Reporter | 검증 방법 | Dependency |
|-------|-------|----------|-------------|----------|-----------|------------|
| **UR_E01** | PoC | **Must** | 로봇은 사람과 부딪혀도 다치지 않도록 제한된 속도와 힘으로만 움직인다. | ■ Safety | 위험성 평가 문서 작성 | - |
| **UR_E02** | PoC | **Must** | 비상 정지 버튼은 로봇 본체 + 작업자용 무선 리모컨 + 안전관리자용 무선 리모컨으로 제공한다. | ■ Safety | 비상정지 작동 시험 | - |
| **UR_E03** | PoC | **Must** | 무선 통신 끊김, 배터리 부족, 위치 파악 불가 시 로봇은 즉시 정지하고 안전 자세를 취한다. | ■ Safety | 이상 상황 시뮬레이션 시험 | - |
| **UR_E04** | Post-PoC | **Should** | 위험한 공사 구역에는 가상 경계를 설정해서 로봇이 절대 들어가지 못하게 한다. | ■ Safety | 경계 침범 여부 확인 | UR_B01 |
| **UR_E05** | Post-PoC | **Should** | 사고나 아차 사고 발생 시 직전/직후의 영상과 센서 데이터를 블랙박스에 저장한다. | ■ Safety | 블랙박스 저장 시험 | - |
| **UR_E06** | PoC | **Must** | 이동할 때는 양팔을 몸에 붙인 자세 유지. 공구를 다룰 때만 팔을 편다. | ■ Safety | 모드 전환 위반 여부 확인 | - |
| **UR_E07** | PoC | **Must** | 본 시스템은 "통제된 실내 환경에서의 시험 운용"으로 한정. 실제 현장 배포 시 별도 인증 필요. | ■ Safety | 운용 범위 문서 명시 | - |

## 변경 이력 (v1.2 → v1.3)

1. **Acceptance Criteria 컬럼의 모든 정량 기준(거리, 속도, 시간, 성공률 등) SR 문서로 이관**
2. **컬럼명 "Acceptance Criteria" → "검증 방법"으로 변경** (정성적 검증 방법만 기재)
3. **Description에서도 구체적 수치 제거** (예: "초당 25cm 이하" → "안전한 수준으로 제한")
4. **UR = What(무엇을), SR = How(어떻게 + 얼마나) 역할 분리 완료**
