## 시뮬레이션 게이팅 SLA

| 항목 | 기준 | 비고 |
|---|---|---|
| Gazebo 시뮬레이션 | 실기체 실행 전 **반드시 통과** | 예외 없음 |
| Isaac Sim 시뮬레이션 | 실기체 실행 전 **반드시 통과** | 예외 없음 |
| 시뮬레이션 실패 시 | 원인 분석 → 수정 → 재시뮬 | 바이패스 금지 |

## 하드웨어 안전 기준

| 항목 | 기준 |
|---|---|
| OpenArm 페이로드 | ≤ 4.1 kg (엔드이펙터 포함) |
| 페이로드 경고 임계값 | ≥ 3.5 kg 시 에스컬레이션 |
| 비상 정지 | 모든 노드에 E-Stop 구독 필수 |
| 충돌 감지 | MoveIt 2 장면 충돌 검사 활성화 필수 |

## 소프트웨어 안정성 기준

| 항목 | 기준 |
|---|---|
| 커밋 전 검증 | `verify-task.sh` 통과 필수 |
| 테스트 커버리지 | 신규 로직 코드 대비 테스트 존재 필수 |
| 단일 파일 크기 | 500줄 이내 (초과 시 분할) |
| 빌드 성공률 | main 브랜치 100% 빌드 가능 유지 |

## 장애 대응 절차

```
1. 장애 감지 → AI_SEMAPHORE.md 상태 업데이트
2. 원인 분석 → docs/troubleshooting/ 에 기록
3. 수정 및 검증 → verify-task.sh 통과 확인
4. 커밋 → fix(scope): 장애 원인 설명
5. 회고 → 재발 방지 대책 docs/에 기록
```
