# SECURITY.md — 보안 규칙 및 금지 사항

> 최종 수정: 2026-05-05

---

## 비밀 정보 관리

| 규칙 | 설명 |
|---|---|
| `.env`, `.secrets` 커밋 금지 | `.gitignore`에 등록 확인 필수 |
| API 키 하드코딩 금지 | 환경 변수 또는 시크릿 매니저 사용 |
| 서버 접속 정보 코드 포함 금지 | 별도 `.env` 파일로 관리 |
| IP/포트 하드코딩 금지 | ROS 2 파라미터 또는 환경 변수 사용 |

## Git 보안

| 규칙 | 설명 |
|---|---|
| `git push --force` 금지 | 히스토리 손실 방지 |
| 대용량 바이너리 커밋 금지 | mesh 파일은 Git LFS 또는 별도 관리 |
| `.bak` 파일 커밋 금지 | `.gitignore`에 등록 확인 필수 |

## 컨테이너 보안

| 규칙 | 설명 |
|---|---|
| `--privileged` 플래그 최소화 | 필요 시 구체적 capability만 부여 |
| 루트 사용자로 컨테이너 실행 자제 | 비특권 사용자 사용 권장 |
| 이미지 태그 `latest` 사용 금지 | 버전 고정 필수 |
| 무단 컨테이너 삭제 금지 | `AI_SEMAPHORE.md` 확인 후 합의 |

## 네트워크 보안

| 규칙 | 설명 |
|---|---|
| 외부 네트워크 노출 최소화 | ROS 2 DDS는 로컬 네트워크 한정 |
| 포트 사용 시 `AI_SEMAPHORE.md` 등록 | 포트 충돌 방지 |
| FastDDS Discovery Server 사용 | 멀티캐스트 대신 유니캐스트 |

## 코드 보안

| 규칙 | 설명 |
|---|---|
| `eval()` / `exec()` 사용 금지 | 코드 인젝션 방지 |
| 사용자 입력 검증 필수 | ROS 서비스/액션 입력값 범위 체크 |
| 외부 패키지 설치 전 승인 | 새 pip/apt 패키지 추가 시 사용자 확인 |
