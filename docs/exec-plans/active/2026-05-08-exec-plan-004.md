# 실행 계획: shutdown-shortcut

> 생성일: 2026-05-08 | 브랜치: chore/archive-exec-plans-pr8

## 목표
세션 종료 전 확인 절차를 `fe` 단축 흐름으로 표준화해, 종료 직전 상태 점검과 체크리스트 확인을 빠르게 수행할 수 있게 한다.

## 접근법
시작용 `fs`/`fsl`과 같은 방식으로 종료용 텍스트 파일과 출력 스크립트를 추가하고, alias 예시를 문서에 반영한다.

## 단계별 계획
- [ ] 1. 종료 체크 텍스트 정의
- [ ] 2. 종료 출력 스크립트 추가
- [ ] 3. agent-protocol README에 사용 예시 반영
- [ ] 4. 로컬 출력 테스트

## 완료 기준
- `fe` alias에 연결할 수 있는 종료용 출력 경로 존재
- 현재 브랜치, git status, 최근 커밋, 종료 체크리스트를 한 번에 확인 가능
- 문서에 alias 사용 예시가 반영됨

## 제약 사항
- 자동 push/commit 등 파괴적 동작은 포함하지 않는다
- 종료 전 최종 판단은 사용자가 하도록 유지한다

## 예상 소요 시간
15분
