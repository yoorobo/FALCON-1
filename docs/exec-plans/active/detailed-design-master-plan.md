# 실행 계획: detailed-design-master-plan

> 생성일: 2026-05-06 | 브랜치: docs/detailed-design-master-plan

## 목표
SR v2.0(81건) 기준으로 7종 상세설계 문서 작성 계획(마스터 플랜)을 수립하고 SR 위임/참조 매핑을 재작성한다.

## 접근법
요구사항 원문과 가이드라인을 우선 분석하고, SR의 "상세설계 위임/참조" 컬럼에서 문서별 SR ID를 정확 추출한 뒤 문서별 목차/참조근거/의존성을 통합한다.

## 단계별 계획
- [ ] 1. SR/UR/가이드라인/기술조사/ShopPinkki/기존 초안 수집 및 구조 파악
- [ ] 2. SR "상세설계 위임/참조" 컬럼 기반 7종 문서 SR ID 매핑표 작성
- [ ] 3. 문서별 H2/H3 뼈대, 차용 포인트, 기술조사 참조, 작성 순서/의존성 정리
- [ ] 4. `docs/design-docs/FALCON-1_Detailed_Design_Master_Plan.md` 작성
- [ ] 5. 검증 스크립트 실행 후 스테이징/커밋

## 완료 기준
- 지정된 경로에 마스터 플랜 문서가 생성되어 있고 7종 문서 각각에 필수 5항목이 포함된다.
- SR ID 매핑은 SR v2.0 원문 컬럼 근거를 따른다.
- `bash scripts/verify-task.sh` 실행 결과를 확보하고 커밋이 생성된다.

## 제약 사항
- SR에 없는 기술 종속 항목을 SR 매핑에 임의 추가하지 않는다.
- P-NN 임계값 TBD 5건은 상세설계 해결 대상에서 제외한다.
- 사용자 요청 범위를 벗어난 산출물은 작성하지 않는다.
