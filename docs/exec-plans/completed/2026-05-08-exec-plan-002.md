# 실행 계획: agent-bootstrap-and-reference-hub

> 생성일: 2026-05-08 | 브랜치: docs/github-centric-ops

## 목표
Confluence 축소를 전제로 FALCON-1의 세션 시작 절차를 레포 문서로 고정하고, Notion 참고자료 허브의 통합 구조를 정의한다.

## 접근법
GitHub에는 재사용 가능한 부트스트랩 문서를 두고, Notion에는 외부 참고자료 허브 구조와 운영 규칙을 페이지로 정리한다.

## 단계별 계획
- [x] 1. 레포 내 부트스트랩 문서 위치와 내용 정의
- [x] 2. `docs/agent-protocol/SESSION_BOOTSTRAP.md` 작성
- [x] 3. 관련 README 또는 운영 문서에서 새 문서 참조 가능성 점검
- [x] 4. Notion 참고자료 허브 구조안 페이지 생성
- [x] 5. 결과 검토 및 다음 사용 방법 정리

## 완료 기준
- 새 AI 세션에서 복붙할 수 있는 짧은 부트스트랩 문서가 레포에 존재
- Confluence를 대체할 Notion 참고자료 허브 구조안이 명시됨
- GitHub와 Notion의 역할 분리가 문서상 일관됨

## 제약 사항
- 기존 운영 규칙과 충돌하지 않도록 최소 범위로 추가한다
- 비밀 정보나 계정 정보는 새 문서에 직접 넣지 않는다
