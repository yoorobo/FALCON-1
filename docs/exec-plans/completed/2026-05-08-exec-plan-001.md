# 실행 계획: github-centric-ops

> 생성일: 2026-05-08 | 브랜치: main

## 목표
FALCON-1의 GitHub 중심 운영 규칙을 레포에 명시하고, 어디서든 동일한 작업 흐름을 재현할 수 있게 템플릿과 진입 문서를 정비한다.

## 접근법
현재 README, CLAUDE 규칙, Notion 운영 방향을 맞춰서 GitHub를 단일 실행 기준점으로 선언하고, Issue/PR 템플릿으로 실제 입력 형식을 고정한다.

## 단계별 계획
- [x] 1. 운영 문서 구조 설계 및 편집 대상 확정
- [x] 2. GitHub 중심 운영 가이드 문서 추가
- [x] 3. README에 Claude+Codex 교차검증 및 GitHub/Notion 역할 분리 반영
- [x] 4. `.github`에 Issue / PR 템플릿 추가
- [x] 5. 문서 일관성 검토

## 완료 기준
- GitHub를 단일 실행 기준점으로 설명하는 문서가 레포 내 존재
- 새 Issue/PR 작성 시 필요한 메타정보를 템플릿이 강제
- README만 읽어도 GitHub와 Notion의 역할 분리가 이해 가능

## 제약 사항
- 기존 설계 문서와 CI 설정은 불필요하게 건드리지 않는다
- Notion 자체 구조 변경은 제안만 하고, 레포 변경 범위에 집중한다
